# SobatNira Flutter

`flutter run` membuka Beranda, Kloter, Laporan, dan Pengaturan dengan simulasi lokal owner/manager. Ikuti [panduan setup](../../docs/development.md) untuk memilih perangkat atau menjalankan smoke test Flutter bersama NestJS dan FastAPI.

Tipografi mengikuti Figma menggunakan [Inter](https://github.com/google/fonts/tree/main/ofl/inter) dengan [lisensi OFL](assets/sobatnira/fonts/OFL.txt).
