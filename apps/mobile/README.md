# SobatNira Flutter

`flutter run` membuka onboarding demo. Isi nama pengguna dan kata sandi dengan teks sintetis untuk masuk ke Beranda, Kloter, Laporan, dan Pengaturan. Form hanya memvalidasi kolom terisi dan sesi berakhir saat aplikasi dimulai ulang. Ikuti [panduan setup](../../docs/development.md) untuk memilih perangkat atau menjalankan smoke test Flutter bersama NestJS dan FastAPI.

Tipografi mengikuti Figma menggunakan [Inter](https://github.com/google/fonts/tree/main/ofl/inter) dengan [lisensi OFL](assets/sobatnira/fonts/OFL.txt).
